# 🌐 Network Types

My networking study notes focused on network classifications, cloud service models, and infrastructure concepts.

Understanding network types is essential for cybersecurity, SOC operations, cloud computing, and IT infrastructure.

---

# PAN (Personal Area Network)

A **PAN** is a small network used to connect personal devices over short distances.

Examples:

* Smartphones
* Wireless keyboards
* Mouses
* Printers
* Tablets

Common technology:

* Bluetooth

Example:

A smartphone connected to a wireless headset using Bluetooth.

---

# LAN (Local Area Network)

A **LAN** connects devices within a small geographic area.

Common environments:

* Homes
* Small businesses
* Schools
* Company departments

Characteristics:

* High speed
* Local management
* Usually uses Ethernet or Wi-Fi

Example:

A company's internal network connecting computers and printers.

---

# VLAN (Virtual Local Area Network)

A **VLAN** is a logical segmentation of a physical network.

It allows administrators to divide a single switch into multiple virtual networks.

Benefits:

* Traffic isolation
* Better security
* Network organization
* Improved management

Example:

A company separates:

```
VLAN 10 - Finance
VLAN 20 - IT
VLAN 30 - Guests
```

Each group works on a different logical network.

---

# WLAN (Wireless Local Area Network)

A **WLAN** is a LAN that uses wireless communication instead of physical cables.

Common technology:

* Wi-Fi

Examples:

* Home Wi-Fi network
* Office wireless network

---

# WMN (Wireless Mesh Network)

A **WMN** uses multiple wireless access points to extend network coverage.

Benefits:

* Larger coverage area
* Better connectivity
* Easy expansion

Examples:

* Large companies
* Universities
* Smart cities

---

# CAN (Campus Area Network)

A **CAN** connects multiple LANs belonging to the same organization in a limited area.

Examples:

* University campus
* Corporate campus

Usually uses:

* Fiber optic connections
* High-speed Ethernet

---

# MAN (Metropolitan Area Network)

A **MAN** covers a larger geographic area, usually a city or metropolitan region.

Examples:

* City networks
* Internet provider infrastructure

Common technologies:

* Fiber optic links
* Wireless backbones

---

# WAN (Wide Area Network)

A **WAN** connects networks located in different geographic areas.

Examples:

* Company branches in different cities
* Internet

Companies usually use WAN services provided by:

* Internet Service Providers (ISPs)
* Telecommunications companies

---

# VPN (Virtual Private Network)

A **VPN** creates a secure connection through an insecure network such as the Internet.

Common uses:

* Remote work
* Secure access to company networks
* Protecting data communication

Example:

An employee connects from home to the company's internal network using VPN.

---

# Cloud Service Models

Cloud computing services are commonly divided into:

* SaaS
* PaaS
* IaaS
* XaaS

---

# SaaS (Software as a Service)

Provides complete applications through the internet.

The user only needs access through a browser or application.

Examples:

* Google Docs
* Microsoft 365
* Salesforce

The provider manages:

* Infrastructure
* Updates
* Maintenance

---

# PaaS (Platform as a Service)

Provides an environment for developers to build and deploy applications.

The developer focuses on code while the provider manages infrastructure.

Examples:

* AWS Elastic Beanstalk
* Google App Engine
* Azure App Services

---

# IaaS (Infrastructure as a Service)

Provides virtualized infrastructure resources.

Examples:

* Virtual machines
* Storage
* Networks

Examples of providers:

* AWS
* Microsoft Azure
* Google Cloud

The customer manages:

* Applications
* Operating systems
* Configurations

---

# XaaS (Everything as a Service)

XaaS represents the idea that many technologies can be delivered as services through the cloud.

Examples:

* DRaaS (Disaster Recovery as a Service)
* DaaS (Desktop as a Service)
* MaaS (Monitoring as a Service)
* CaaS (Communication as a Service)

---

# Cybersecurity Importance

Understanding network types helps security professionals:

* Analyze network architecture
* Understand attack surfaces
* Configure security controls
* Investigate incidents
* Protect cloud environments

SOC analysts need to understand where devices are located and how they communicate.
